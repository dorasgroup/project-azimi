# فاز چهارم — رتبه‌بندی هیبریدی کاندیدهای خزش

## وضعیت

وضعیت اجرایی: **کامل و آماده تأیید کاربر**  
تاریخ اجرا: ۱۴۰۵/۰۵/۰۵ (2026-07-27)

## هدف

انتخاب URLهای مرتبط‌تر از میان خروجی RSS، sitemap، HTML، search، GDELT، Common Crawl و archive، بدون تغییر موضوع canonical رصد و بدون افزودن تأخیر شبکه یا مدل زبانی.

## معماری

این فاز سه مسئولیت مستقل دارد:

- `Bm25LexicalScorer`: سنجش تطابق واژگانی عنوان و مسیر URL با query plan چندزبانه فاز سوم؛
- `HybridCandidateScorer`: ترکیب امتیاز واژگانی، پوشش مفهومی، اعتبار مدرک/provider، شواهد زمانی و ساختار URL؛
- `CandidateRanker`: حذف تاریخ‌های قطعاً خارج از بازه، اعمال تنوع provider و انتخاب حداکثر تعداد مجاز.

موضوع اصلی فقط ورودی read-only امتیازدهی است و هیچ‌گاه بازنویسی یا به legacy workflow engine ارسال نمی‌شود.

## مدل امتیاز

| مؤلفه | وزن |
|---|---:|
| BM25 واژگانی چندزبانه | 0.35 |
| پوشش مفاهیم موضوع | 0.30 |
| اعتبار provider و provenance | 0.20 |
| شواهد زمانی | 0.10 |
| ساختار عنوان/URL | 0.05 |

امتیاز همه مؤلفه‌ها به بازه صفر تا یک نرمال می‌شود. سپس تنوع provider در مرحله انتخاب اعمال می‌شود تا یک provider تمام ظرفیت را اشغال نکند.

## قابلیت توضیح‌پذیری

رویداد ساخت‌یافته `crawl_candidate_ranking` شامل موارد زیر ثبت می‌شود:

- فعال یا غیرفعال بودن روش هیبریدی؛
- تعداد کاندید، کاندید واجد شرایط و انتخاب‌شده؛
- وزن‌ها؛
- URL، provider، وضعیت انتخاب و تفکیک امتیاز پنج مؤلفه برای نتایج برتر؛
- تأیید حفظ موضوع canonical.

این trace حاوی متن کامل سند، کلید API یا داده محرمانه نیست.

## سازگاری و بازگشت

امضای قبلی `rank(candidates, policy, date_window)` حفظ شده است و `topic` اختیاری است. اگر موضوع ارسال نشود یا متغیر زیر خاموش باشد، دقیقاً مسیر رتبه‌بندی قدیمی اجرا می‌شود:

```dotenv
CRAWL_HYBRID_RANKING_ENABLED=false
```

پس از تغییر متغیر، worker باید بازراه‌اندازی شود.

## نتیجه پذیرش

- lint فایل‌های فاز: موفق؛
- تست هدفمند: ۱۴ موفق؛
- suite کامل backend: ۱۳۳ موفق، ۴ skipped؛
- fixture برچسب‌خورده: Precision@3 و Recall@3 از 0.3333 به 1.0 و MRR از 0.5 به 1.0 رسید؛
- بنچمارک ۵۰۰۰ کاندید: 1296.09 میلی‌ثانیه؛
- فراخوانی شبکه یا مدل در ranking: صفر؛
- موضوع canonical: بدون تغییر؛
- مسیر legacy و تنوع provider: دارای تست رگرسیون.
