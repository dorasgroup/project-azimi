# راهنمای اجرای MVP

این سند خروجی فاز شانزده پروژه «رصد و تحلیل» است و روش اجرای نسخه اول محلی را توضیح می‌دهد.

## هدف فاز

در فاز شانزده، MVP از حالت مجموعه قابلیت‌های جداگانه به یک سناریوی اجرایی تبدیل شد:

- منابع خبری از API قابل ایجاد، فهرست، ویرایش، حذف و بررسی اتصال هستند.
- هویت تحلیلگر از API قابل ایجاد، فهرست، ویرایش، حذف و فعال‌سازی است.
- فرانت‌اند از حالت داده نمایشی به حالت متصل به API واقعی تغییر کرد.
- کاربر demo محلی قابل seed شدن است.
- سناریوی کامل ورود، ساخت منبع، ساخت هویت، ایجاد job، تکمیل تحلیل legacy workflow engine، مشاهده گزارش و دانلود PDF/Word با HTTP واقعی بررسی می‌شود.

## راه‌اندازی سرویس‌ها

```powershell
docker compose --env-file .env -f docker/compose.yml --profile worker up -d
```

آدرس‌ها:

- فرانت‌اند: `http://localhost:5173`
- API: `http://localhost:8010`
- OpenAPI: `http://localhost:8010/docs`

## آماده‌سازی کاربر demo

```powershell
docker compose --env-file .env -f docker/compose.yml exec -T api python -m scripts.seed_mvp
```

اطلاعات ورود محلی:

- نام کاربری: `mvp_admin`
- رمز عبور: `MvpDemoPass123!`

این حساب فقط برای اجرای محلی MVP است و در محیط واقعی باید حذف یا رمز آن تغییر داده شود.

## اجرای سناریوی پذیرش MVP

```powershell
docker compose --env-file .env -f docker/compose.yml exec -T api python -m scripts.verify_mvp
```

این سناریو موارد زیر را با API واقعی بررسی می‌کند:

1. سلامت API
2. ورود کاربر مدیر
3. ایجاد منبع خبری
4. بررسی اتصال منبع
5. ایجاد و فعال‌سازی هویت تحلیلگر
6. ایجاد job رصد
7. انتظار تا تکمیل job
8. مشاهده گزارش ذخیره‌شده
9. دانلود PDF و Word

آخرین اجرای فاز شانزده موفق بود و job با گزارش نهایی تکمیل شد.

## اجرای MVP از رابط کاربری

1. ابتدا دستور seed را اجرا کنید.
2. به `http://localhost:5173` بروید.
3. با `mvp_admin` و `MvpDemoPass123!` وارد شوید.
4. در صورت نیاز منبع جدید ثبت کنید یا اتصال منبع موجود را بررسی کنید.
5. هویت تحلیلگر را ثبت و فعال کنید.
6. job رصد را با موضوع و بازه شمسی ایجاد کنید.
7. وضعیت jobها را در همان صفحه دنبال کنید.
8. پس از تکمیل، گزارش را در بخش گزارش‌ها ببینید و PDF/Word را دانلود کنید.

## مرز MVP

این نسخه محلی است و برای demo و پذیرش نسخه اول طراحی شده است. موارد زیر همچنان خارج از محدوده نسخه اول هستند:

- استقرار عمومی یا ابری
- زمان‌بندی خودکار رصد
- اعلان و پیام‌رسانی
- داشبورد تحلیلی پیشرفته
- اتصال شبکه‌های اجتماعی
- تست E2E مرورگری کامل
