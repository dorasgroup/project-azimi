# نقشه راه نسخه حرفه‌ای‌تر

این سند خروجی فاز هفده پروژه «رصد و تحلیل» است. در این فاز، پروژه از وضعیت MVP قابل اجرا به سمت یک پایه حرفه‌ای‌تر حرکت کرد و هم‌زمان موارد بعدی که خارج از فازبندی فعلی هستند، شفاف شدند.

## خروجی فاز هفده

- endpoint جدید `GET /api/v1/dashboard/summary` برای نمایش خلاصه مدیریتی اضافه شد.
- خلاصه داشبورد شامل شمارش کاربران، منابع، منابع فعال، هویت‌های تحلیلگر، jobها، گزارش‌ها و خطاهای سیستمی است.
- وضعیت jobها بر اساس enumهای فعلی سیستم شمارش می‌شود تا داشبورد بتواند وضعیت‌های `pending`، `running`، `completed`، `failed` و `cancelled` را نمایش دهد.
- jobها و گزارش‌های اخیر در خروجی داشبورد قرار گرفتند.
- دسترسی داشبورد برای کاربر احرازشده فعال است؛ کاربر عادی فقط داده‌های قابل مشاهده خود را می‌بیند و `super_admin` خلاصه کل سیستم را می‌بیند.
- کارت‌های آماری اصلی فرانت‌اند به همین endpoint متصل شدند و دیگر از محاسبه پراکنده روی داده‌های نمایشی استفاده نمی‌کنند.
- آزمون پذیرش `scripts.verify_professional_features` اضافه شد و در runner جامع پروژه قرار گرفت.

## نقشه راه پیشنهادی پس از فاز هفده

فازبندی فعلی با فاز هفده به پایان می‌رسد. موارد زیر شروع نشده‌اند و برای ادامه پروژه باید به‌عنوان نسخه یا فاز جدید تعریف، اولویت‌بندی و تأیید شوند.

### اولویت نزدیک

- زمان‌بندی رصدهای تکرارشونده برای اجرای روزانه، هفتگی یا بازه‌های سفارشی.
- اعلان داخلی یا ایمیلی برای تکمیل گزارش، شکست job یا خطای منبع خبری.
- نمایش زنده وضعیت jobها با WebSocket یا polling کنترل‌شده.
- تست مرورگری end-to-end برای سناریوی ورود، ایجاد رصد، مشاهده گزارش و دانلود خروجی.
- audit log امنیتی برای عملیات حساس مانند ورود، تغییر رمز، ایجاد کاربر و حذف گزارش.

### اولویت میانی

- داشبورد تحلیلی پیشرفته با نمودار روند jobها، منابع پرتکرار، نرخ خطا و وضعیت گزارش‌ها.
- شاخص‌های سنجش احساس، شدت روایت، سطح ریسک و میزان همگرایی منابع.
- جستجوی معنایی در گزارش‌ها و اسناد خزیده‌شده با vector database.
- مدیریت قالب‌های گزارش سازمانی، header/footer سفارشی و شماره صفحه در خروجی PDF.
- اتصال به منابع اجتماعی یا کانال‌های داده جدید در کنار سایت‌های خبری.

### اولویت بلندمدت

- تشخیص شبکه روایت و خوشه‌بندی روایت‌های مشابه در چند منبع.
- تحلیل مقایسه‌ای دوره‌ای برای تشخیص تغییر لحن، تغییر framing و تکرار الگوهای عملیات روانی.
- MFA، rate limiting دقیق‌تر، سیاست‌های پیشرفته مالکیت داده و CSRF برای کلاینت‌های cookie-based.
- استقرار production با backup، مانیتورینگ بیرونی، retention policy، alerting و secret management.
- چندمستاجری سازمانی، سطوح دسترسی جزئی‌تر و مدیریت تیم‌ها.

## آزمون پذیرش فاز هفده

بررسی مستقل قابلیت حرفه‌ای اضافه‌شده:

```powershell
docker compose --env-file .env -f docker/compose.yml exec -T api python -m scripts.verify_professional_features
```

اجرای کامل آزمون‌های پروژه:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/verify_project.ps1
```

## وضعیت نهایی

فاز هفده پایان فازبندی فعلی پروژه است. ادامه توسعه، از نظر مدیریتی و فنی، باید به‌عنوان فاز یا نسخه جدید تعریف شود تا محدوده، اولویت، معیار پذیرش و ریسک‌های آن روشن باشد.
