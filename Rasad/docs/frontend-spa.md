# طراحی فرانت‌اند SPA

## وضعیت فاز هشت

- پوسته کامل SPA فارسی، RTL و واکنش‌گرا پیاده‌سازی شده است.
- پنج تب اصلی، منوی تنظیمات، modal گزارش و modal جزئیات خطای منبع قابل تعامل هستند.
- در فاز هشت داده‌ها نمایشی بودند؛ در فاز شانزده، پوسته MVP به API واقعی متصل شد تا ورود، منابع، هویت تحلیلگر، jobها، گزارش‌ها و دانلود خروجی‌ها از بک‌اند خوانده یا اجرا شوند.
- در فاز هفده، کارت‌های آماری اصلی داشبورد به مسیر `GET /dashboard/summary` متصل شدند تا خلاصه سیستم از یک endpoint متمرکز و قابل آزمون خوانده شود.
- پس از بازبینی فازهای ۱ تا ۱۷، پوسته کامل پنج‌تب با اتصال واقعی API، modalها، منوی تنظیمات، خروج، جستجو، فیلتر، انتخاب منابع و دانلود گزارش دوباره یکپارچه و آزمون شد.

## سیستم طراحی

- پالت اصلی بر اساس رنگ‌های پروژه: قرمز گرم، کرم و پس‌زمینه روشن
- کارت‌های نرم با border ظریف و سایه کم
- سلسله‌مراتب بصری واضح برای عنوان صفحه، بخش، وضعیت و عملیات
- آیکن‌های SVG داخلی بدون وابستگی به کتابخانه یا CDN خارجی
- فونت با اولویت `Vazirmatn` نصب‌شده روی میزبان و fallback محلی `Tahoma`
- نمایش وضعیت‌های موفق، هشدار، خطا و پردازش با badgeهای متمایز

## ساختار SPA

| بخش | محتوای پیاده‌سازی‌شده |
| --- | --- |
| رصد تازه | فرم موضوع، بازه شمسی، هویت تحلیلگر، انتخاب منابع و رصدهای اخیر |
| منابع | آمار وضعیت، جستجو، جدول منابع، عملیات و modal خطای اتصال |
| گزارش‌ها | جستجو، فیلتر، کارت گزارش، برچسب‌ها و modal نمایش گزارش |
| هویت تحلیلگر | فرم نقش، لحن، سبک، چارچوب شناختی و پیش‌نمایش هویت |
| کاربران | جدول کاربران، نقش، وضعیت و عملیات مدیریتی |
| تنظیمات | ویرایش حساب، تغییر رمز و خروج |

## واکنش‌گرایی

- در دسکتاپ، ناوبری در header و محتوای چندستونه نمایش داده می‌شود.
- در تبلت، شبکه‌ها به ستون‌های کمتر تبدیل می‌شوند.
- در موبایل، ناوبری به نوار ثابت پایین صفحه منتقل می‌شود.
- فرم‌ها و کارت‌ها تک‌ستونه می‌شوند و جدول‌ها فقط در محدوده خود اسکرول افقی دارند.
- ایراد اولیه گسترش عرض صفحه توسط جدول در آزمون مرورگر شناسایی و با `minmax(0, 1fr)` رفع شد.

## تعاملات پیاده‌سازی‌شده

- جابه‌جایی آنی میان تب‌ها
- انتخاب و لغو انتخاب منابع
- نمایش منوی تنظیمات کاربر
- نمایش جزئیات خطای اتصال منبع
- نمایش خلاصه و یافته‌های گزارش
- نمایش زنده سلامت API و دیتابیس در header و footer
- نمایش آمار متمرکز داشبورد شامل منابع فعال، jobهای تکمیل‌شده، گزارش‌ها و خطاهای سیستمی

## نتایج آزمون

- `npm run build` بدون خطا اجرا شد.
- `npm run lint` بدون خطا اجرا شد.
- سلامت API در SPA با وضعیت آماده نمایش داده شد.
- همه پنج تب در مرورگر محلی قابل جابه‌جایی هستند.
- modal گزارش و modal خطای اتصال در مرورگر محلی تأیید شدند.
- نمای موبایل با viewport برابر `390x844` بررسی شد و عرض صفحه بدون overflow تأیید شد.
- نمای دسکتاپ با viewport پیش‌فرض `1280x720` بررسی شد.
