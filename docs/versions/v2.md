# نسخه بازیابی v2

این نسخه وضعیت کامل پروژه «رصد و تحلیل» در تاریخ ۱۸ خرداد ۱۴۰۵ را پس از اصلاحات پایداری منابع، رصد، گزارش‌ها و پشتیبانی از منابع غیرفارسی ثبت می‌کند.

## اجزای نسخه

- کد پروژه در Git tag با نام `v2`
- Git bundle مستقل در مسیر `D:\pr\10_versions\v2\rasad-analysis-v2.bundle`
- آرشیو کد در مسیر `D:\pr\10_versions\v2\rasad-analysis-v2-code.zip`
- تنظیمات محلی در مسیر `D:\pr\10_versions\v2\runtime\.env`
- dump کامل PostgreSQL در مسیر `D:\pr\10_versions\v2\runtime\postgres-v2.dump`
- فایل‌های runtime و گزارش‌ها در مسیر `D:\pr\10_versions\v2\runtime\storage`
- فهرست checksum فایل‌های snapshot در مسیر `D:\pr\10_versions\v2\SHA256SUMS.txt`

## نکات مهم v2

- منابع غیرفارسی در رصد حفظ می‌شوند و شواهد آن‌ها برای گزارش نهایی به فارسی ترجمه/بازنویسی می‌شود.
- وضعیت منابع در برابر شکست‌های کاذب مقاوم‌تر شد؛ خطاهای موقت و محدودیت‌های دسترسی به‌صورت خرابی قطعی ثبت نمی‌شوند.
- رصدهای اخیر قابلیت ویرایش، اجرای مجدد و حذف دارند.
- حذف گزارش، رصد مرتبط را نیز از فهرست رصدهای اخیر حذف می‌کند.
- نسخه `v1` همچنان به‌عنوان نقطه بازیابی قبلی باقی مانده است.

## بازگردانی کد

برای بازگردانی همین working tree:

```powershell
git switch --detach v2
```

برای ساخت یک پوشه تازه از نسخه مستقل:

```powershell
git clone D:\pr\10_versions\v2\rasad-analysis-v2.bundle D:\pr\10-restored-v2
Set-Location D:\pr\10-restored-v2
git switch --detach v2
```

## بازگردانی داده‌های runtime

قبل از بازگردانی داده‌ها، سرویس‌های پروژه باید متوقف شوند. سپس فایل `.env` و پوشه `storage` از snapshot به ریشه پروژه کپی و dump دیتابیس داخل PostgreSQL بازیابی می‌شود.

نسخه snapshot محلی شامل اطلاعات حساس تنظیمات است و نباید در مخزن عمومی یا فضای اشتراکی آپلود شود.
