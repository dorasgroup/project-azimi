# نسخه بازیابی v1

این نسخه وضعیت کامل پروژه «رصد و تحلیل» در تاریخ ۱۸ خرداد ۱۴۰۵ را ثبت می‌کند.

## اجزای نسخه

- کد پروژه در Git tag با نام `v1`
- Git bundle مستقل در مسیر `D:\pr\10_versions\v1\rasad-analysis-v1.bundle`
- تنظیمات محلی در مسیر `D:\pr\10_versions\v1\runtime\.env`
- dump کامل PostgreSQL در مسیر `D:\pr\10_versions\v1\runtime\postgres-v1.dump`
- فایل‌های runtime و گزارش‌ها در مسیر `D:\pr\10_versions\v1\runtime\storage`
- فهرست checksum فایل‌های snapshot در مسیر `D:\pr\10_versions\v1\SHA256SUMS.txt`

## بازگردانی کد

برای بازگردانی همین working tree:

```powershell
git switch --detach v1
```

برای ساخت یک پوشه تازه از نسخه مستقل:

```powershell
git clone D:\pr\10_versions\v1\rasad-analysis-v1.bundle D:\pr\10-restored-v1
Set-Location D:\pr\10-restored-v1
git switch --detach v1
```

## بازگردانی داده‌های runtime

قبل از بازگردانی داده‌ها، سرویس‌های پروژه باید متوقف شوند. سپس فایل `.env` و پوشه `storage` از snapshot به ریشه پروژه کپی و dump دیتابیس داخل PostgreSQL بازیابی می‌شود.

نسخه snapshot محلی شامل اطلاعات حساس تنظیمات است و نباید در مخزن عمومی یا فضای اشتراکی آپلود شود.
