1. ده دامنه عمومی در Worker به `10.10.34.36` نگاشت می‌شوند و محافظ SSRF آن‌ها را رد می‌کند.
2. سقف ۸۰ صفحه هزاران URL را پیش از دریافت کنار می‌گذارد.
3. بازده پذیرش ۱۵٫۸۳٪ نشان می‌دهد بخش زیادی از بودجه روی صفحات نامرتبط مصرف می‌شود.
4. منبع «شرق» به `mashreghnews.ir` اشاره می‌کند و نیازمند اصلاح کاتالوگ است.
5. `Python.org` یک منبع آزمایشی و نامرتبط با رصد خبری است.
